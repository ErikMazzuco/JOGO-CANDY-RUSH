# 🍬 Candy Rush

**Candy Rush** é um jogo desenvolvido na Unity para a disciplina de **Realidade Virtual (RV)**, como parte de um projeto acadêmico.

Inspirado em jogos do estilo *endless runner*, como Subway Surfers, o jogo desafia o jogador a desviar de obstáculos, trocar de faixa e coletar itens durante o percurso em um cenário temático de doces.

## 🎮 Sobre o jogo

O objetivo é percorrer o cenário até chegar ao final, evitando os obstáculos e coletando itens pelo caminho.

O jogador pode se movimentar entre três faixas, pular obstáculos e explorar um ambiente colorido inspirado no universo dos doces.

## 🕹️ Controles

| Tecla | Ação |
|---|---|
| **A** | Mover para a faixa da esquerda |
| **D** | Mover para a faixa da direita |
| **Espaço** | Pular |

## ✨ Funcionalidades

- Movimentação automática do personagem pelo cenário.
- Sistema de movimentação entre três faixas.
- Desvio de obstáculos durante o percurso.
- Pulo para superar obstáculos.
- Coleta de itens espalhados pelo cenário.
- Sistema de pontuação baseado nos itens coletados.
- Cenário 3D temático de doces.

## 🛠️ Tecnologias utilizadas

- **Unity** — desenvolvimento do jogo.
- **C#** — programação das mecânicas e comportamentos.
- **Blender** — criação e edição de modelos 3D, quando aplicável.

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/ErikMazzuco/JOGO-CANDY-RUSH.git
   ```

2. Abra o Unity Hub.
3. Selecione a opção para adicionar ou abrir um projeto existente.
4. Escolha a pasta do projeto clonado.
5. Abra o projeto com uma versão compatível da Unity.
6. Abra a cena principal e clique em **Play** para iniciar o jogo.

## 🎓 Objetivo acadêmico

O projeto foi desenvolvido para a disciplina de Realidade Virtual, com o objetivo de aplicar conhecimentos de desenvolvimento de jogos 3D, programação, movimentação de personagens, colisões e interação com objetos em um ambiente virtual.
